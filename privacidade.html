Política de Privacidade

Última atualização: 25 de novembro de 2026

Em resumo
  • Podes usar a app sem conta: os teus dados ficam só no teu aparelho.
  • Nunca pedimos as credenciais do teu banco e não nos ligamos ao teu banco.
  • Os extratos que importas são lidos no teu aparelho e não são enviados para nós.
  • Se criares conta, os dados são guardados no nosso servidor para sincronizar entre aparelhos.
  • Não vendemos os teus dados e os teus dados financeiros nunca são usados para publicidade.
  • No plano grátis do Android aparecem anúncios do Google AdMob (ver secção 4).
  • Exportas ou apagas tudo quando quiseres.

1. Quem é responsável pelos dados

O MyFuturePal é um projeto independente. O responsável pelo tratamento dos dados pode ser contactado em futurepal.support@gmail.com. É para este endereço que deves enviar qualquer pedido sobre os teus dados.

3. Com quem partilhamos

Só com fornecedores necessários para a app funcionar, que tratam os dados por nossa conta:

  • Supabase: alojamento da base de dados, autenticação e armazenamento das contas com sincronização.
  • Google: só se escolheres entrar com a conta Google.
  • Fornecedor de IA (por exemplo, Groq): recebe a pergunta ao assistente e o resumo necessário, só quando o usas. Se usares a tua própria chave de outro fornecedor (OpenAI, Anthropic, Google Gemini, OpenRouter ou Groq), os pedidos vão diretamente da tua app para esse fornecedor, segundo as regras dele.
  • Google AdMob: anúncios no plano grátis do Android (ver secção 4).
  • GitHub: aloja este website e os ficheiros de instalação e atualização. Pode registar o endereço IP de quem descarrega.

Alguns destes fornecedores podem tratar dados fora do Espaço Económico Europeu. Nesses casos, a transferência é feita com as garantias previstas no RGPD, como as cláusulas contratuais-tipo da Comissão Europeia.

Não vendemos dados pessoais. Os teus movimentos, valores e descrições nunca são partilhados com anunciantes.

4. Anúncios (só no plano grátis do Android)

No plano grátis da app para Android podem aparecer anúncios do Google AdMob (Google Ireland Limited). Para mostrar e medir anúncios, o AdMob pode recolher o identificador de publicidade do teu aparelho, o endereço IP, o modelo do aparelho e dados de interação com os anúncios. O AdMob não recebe os teus dados financeiros.

Anúncios personalizados só são mostrados com o teu consentimento, pedido na própria app quando a lei o exige. Podes limitar ou repor o identificador de publicidade nas definições do Android, ou deixar de ver anúncios com um plano pago. Mais informação na política de publicidade da Google. Na app para PC e no website não há anúncios de terceiros.

5. Estatísticas agregadas

Podemos vir a produzir estatísticas agregadas e anónimas sobre hábitos de despesa (por exemplo, a média gasta numa categoria). Nunca incluem dados de uma pessoa identificável, exigem um número mínimo de pessoas por valor e podes desligar a tua participação nas definições da app. Esta funcionalidade não está ativa à data desta política.

6. Quanto tempo guardamos

Os dados da tua conta ficam guardados enquanto a conta existir. Se apagares a conta, os dados são apagados do servidor. Os dados que ficam só no teu aparelho estão sob o teu controlo e desaparecem quando apagas a app ou os dados nas definições. Se o projeto terminar, avisamos com antecedência na app, para poderes exportar os teus dados antes de serem apagados.

7. Os teus direitos

Podes pedir acesso, retificação, apagamento, limitação, portabilidade ou opor-te ao tratamento dos teus dados. Muitas destas coisas fazes diretamente na app: exportar os dados (cópia de segurança e Excel), corrigir movimentos e apagar a conta. Para o resto, escreve para futurepal.support@gmail.com. Respondemos no prazo de um mês.

Tens também o direito de apresentar reclamação à Comissão Nacional de Proteção de Dados (www.cnpd.pt).

8. Segurança

As ligações ao servidor são cifradas (HTTPS) e cada pessoa só consegue ler os seus próprios dados. Ainda assim, nenhum sistema é totalmente seguro: protege o teu aparelho e a tua palavra-passe.

9. Menores

A app não se destina a menores de 16 anos sem autorização de quem tem a responsabilidade parental.

10. Alterações

Se mudarmos esta política de forma importante, avisamos na app e atualizamos a data no topo desta página.
